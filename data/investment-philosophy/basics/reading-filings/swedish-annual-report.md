# Swedish Annual Report (Årsredovisning)

## Quick Answer

Swedish public companies publish an annual report (årsredovisning) that contains financial statements, management report, and governance information. While the structure differs from US 10-Ks, the key information is the same.

---

## Overview

| Attribute | Details |
|-----------|---------|
| **Swedish Name** | Årsredovisning |
| **Filed By** | Swedish public companies (and private companies over size thresholds) |
| **Accounting Standards** | IFRS for listed companies, K3 for private |
| **Language** | Usually Swedish (some provide English versions) |
| **Where to Find** | Company's investor relations website |

---

## Typical Structure

### Front Matter (First 20-30 pages)

| Section | Swedish Name | Content |
|---------|--------------|---------|
| **CEO Letter** | VD-ord / VD har ordet | CEO's message to shareholders |
| **Year in Brief** | Året i korthet | Key highlights and metrics |
| **Business Overview** | Verksamheten | Description of operations |
| **Market Overview** | Marknaden | Industry and competitive landscape |
| **Strategy** | Strategi | Strategic direction |
| **Segments** | Affärsområden | Business unit descriptions |
| **Sustainability** | Hållbarhet | ESG information |

### Administration Report (Förvaltningsberättelse)

**Required by Swedish law** - Similar to MD&A in US filings.

| Content | Swedish Term |
|---------|--------------|
| Business description | Verksamhetens art och inriktning |
| Significant events | Väsentliga händelser |
| Financial performance | Resultat och ställning |
| R&D activities | Forskning och utveckling |
| Branches abroad | Filialer utomlands |
| Risks | Risker och osäkerhetsfaktorer |
| Outlook | Utsikter |
| Environment | Miljö |
| Personnel | Personal |
| Proposed dividend | Förslag till vinstdisposition |

---

### Financial Statements (Finansiella rapporter)

| Statement | Swedish Name | Notes |
|-----------|--------------|-------|
| **Income Statement** | Resultaträkning | Revenue to net income |
| **Comprehensive Income** | Rapport över totalresultat | Net income + OCI |
| **Balance Sheet** | Balansräkning | Assets, liabilities, equity |
| **Cash Flow Statement** | Kassaflödesanalys | Three sections (operating, investing, financing) |
| **Changes in Equity** | Förändringar i eget kapital | Equity movements |
| **Notes** | Noter | Accounting policies and details |

### Notes (Noter) - Critical Section

Swedish notes typically include:

| Note Topic | Swedish | What to Look For |
|------------|---------|------------------|
| Accounting policies | Redovisningsprinciper | Any changes |
| Revenue | Intäkter | Recognition policies, segments |
| Segment data | Segmentinformation | Revenue/profit by segment |
| Personnel | Personal | Headcount, costs |
| Financial instruments | Finansiella instrument | Fair values, risks |
| Borrowings | Låneskulder | Debt terms, maturities |
| Provisions | Avsättningar | Warranty, restructuring |
| Leases | Leasingavtal | IFRS 16 impact |
| Related parties | Närstående | Transactions with insiders |
| Contingent liabilities | Eventualförpliktelser | Off-balance sheet |
| Events after period | Händelser efter periodens slut | Subsequent events |

---

### Corporate Governance (Bolagsstyrning)

Swedish listed companies must include:

| Section | Content |
|---------|---------|
| Governance Report | Bolagsstyrningsrapport |
| Board of Directors | Styrelse |
| Management | Koncernledning |
| Auditor's statement on governance | Revisorns yttrande |
| Compensation | Ersättningar till ledande befattningshavare |

### Auditor's Report (Revisionsberättelse)

| Section | Content |
|---------|---------|
| Opinion | Uttalande om årsredovisningen |
| Basis for opinion | Grund för uttalandet |
| Key audit matters | Särskilt betydelsefulla områden |
| Going concern | Fortsatt drift |
| Other information | Övrig information |

## Reading Strategy

### Quick Scan (20 minutes)

1. **CEO Letter** - Tone, key messages
2. **Året i korthet** - Year highlights
3. **Finansiella nyckeltal** - Key metrics
4. **Kassaflödesanalys** - Cash flow statement

### Standard Analysis (1-2 hours)

1. CEO Letter and year summary
2. Business and segment descriptions
3. Förvaltningsberättelse (Administration Report)
4. All financial statements
5. Key notes (revenue, debt, segments)
6. Auditor's report

### Deep Dive (3-4 hours)

1. Everything above
2. All notes in detail
3. Corporate governance report
4. Compare to prior year reports
5. Cross-reference with quarterly reports

## Swedish vs US Filings

| Aspect | Swedish (IFRS) | US (10-K) |
|--------|----------------|-----------|
| Format | Designed document (PDF) | Plain text (HTML/PDF) |
| Risk Factors | Part of Förvaltningsberättelse | Dedicated Item 1A |
| MD&A Equivalent | Förvaltningsberättelse | Item 7 MD&A |
| CEO Letter | Almost always included | Sometimes included |
| Sustainability | Often extensive | Increasingly required |
| Language | Swedish (English versions common) | English |
| Filing Location | Company website | SEC EDGAR |

---

## Key Differences from 10-K

1. **More visual**: Swedish reports are designed documents with graphics and photos

2. **CEO Letter**: Almost always present and often more personal

3. **Sustainability**: Typically more extensive sustainability reporting

4. **Format by function or nature**: Expenses can be presented either way

5. **Fewer risk factors**: Less extensive than US Item 1A

6. **Governance report**: Separate section required

## Red Flags (Same as US)

Use Ctrl+F with Swedish terms:

| Swedish Term | English | Why Look |
|--------------|---------|----------|
| "väsentlig osäkerhet" | Material uncertainty | Going concern |
| "anmärkning" | Remark | Auditor concern |
| "ändring av redovisningsprincip" | Change in accounting policy | Manipulation |
| "närstående" | Related party | Self-dealing |
| "eventualförpliktelse" | Contingent liability | Hidden risk |
| "nedskrivning" | Impairment | Asset problems |
| "omstrukturering" | Restructuring | Costs coming |

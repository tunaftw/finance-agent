Proven methodologies for analyzing company filings with demonstrated alpha generation.

## Usage by Task

### Before Reading a Filing
1. Review [Buffett 10-K Method](buffett-10k-method.md) for reading order
2. Prepare the [Red Flags Checklist](../techniques/red-flags-checklist.md)

### During Analysis
1. Check [Schilit 7 Shenanigans](schilit-7-shenanigans.md) for manipulation signs
2. Calculate [Sloan Accruals](sloan-accruals.md) ratio
3. Note red flags as you encounter them

### After Reading
1. Calculate [Piotroski F-Score](piotroski-f-score.md)
2. Estimate intrinsic value using [Graham-Dodd](graham-dodd-intrinsic-value.md)
3. Compare to [Magic Formula](greenblatt-magic-formula.md) ranking

## Framework Combinations

### Value Stock Screen
```
1. High book-to-market ratio (value)
2. Piotroski F-Score >= 7
3. Sloan Accruals ratio < 5%
```

### Quality Screen
```
1. Magic Formula top quintile
2. Piotroski F-Score >= 7
3. No Schilit red flags
```

### Deep Dive Analysis
```
1. Buffett 10-K Method (qualitative)
2. Full Schilit checklist
3. Piotroski F-Score (quantitative)
4. Sloan Accruals (earnings quality)
```
